# Website Download Page Update: Smarter Source Selection

This update focuses on the download experience, helping users in different regions find the right download route faster.

## Smarter Default Download Source

Previously the download page treated everyone the same. Now the default source is recommended based on the visitor's language and region:

- **Chinese pages (domestic)**: 75% chance the default is the Ningze Resource Station (柠泽资源站), otherwise the Fengyuan mirror (枫源镜像) — the two sources rotate randomly to spread load.
- **English pages (overseas)**: the Fengyuan mirror (枫源镜像) is used by default for better speed abroad.

Switching the interface language re-matches the recommended source to the current region. Of course, all sources can still be freely selected from the dropdown.

## Cloud Drive for Domestic Users Only

The cloud drive mirror mainly serves users in China. It is now only shown to domestic visitors, so overseas users no longer see a card they can't use.

## Download Source Renames

- "国内加速" (Domestic Acceleration) is now **Fishcpy Acceleration**.
- "柠枺镜像" (Ningmei Mirror) is now **Ningze Resource Station (柠泽资源站)**.

The download routes themselves are unchanged. Enjoy the new default recommendations!
